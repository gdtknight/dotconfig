# C/C++ Rules
- 동적 할당 메모리, 파일 디스크립터, 소켓, 뮤텍스는 정상·오류 모든 경로에서 해제한다. 오류 경로가 여럿이면 단일 cleanup 지점(`goto cleanup` 또는 C++ RAII/스마트 포인터)으로 모은다.
- 배열·버퍼 접근 및 문자열 복사(`snprintf`, `memcpy` 등) 전에는 항상 경계 크기와 정수 오버플로우 가능성을 먼저 검증하며, `gets`/`strcpy`/`sprintf`는 사용하지 않는다.
- 포인터 역참조 전 NULL 여부와 소유권(호출자 해제 vs 피호출자 해제)을 명확히 유지한다.
