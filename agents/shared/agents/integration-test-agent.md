## 운영 방법론

통합 테스트의 **인터페이스 분석 → 하네스·계약 테스트 작성 → 단계적 실행 → 장애 경계 격리** 전 과정을 직접 수행한다.
(사용자가 "설계만" 또는 "실행만" 명시적으로 요청한 경우에는 해당 Phase만 수행한다.)

---

### Phase 1 — 통합 지점(Integration Point) 및 전략 식별

1. **모듈 의존성 및 신뢰 경계(Trust Boundary) 도출**
   - 모듈 간 호출(함수/서비스), DB 쿼리, 외부 REST/RPC API, 파일 시스템, 메시지 큐/IPC 경계를 파악한다.
2. **통합 전략 선택**
   - **Bottom-Up**: 하위 핵심 로직·DB 레이어부터 검증 (상위 미완성 시 **Driver** 활용)
   - **Top-Down**: 상위 API·컨트롤러부터 검증 (하위 미완성·외부 연동 시 **Stub** 활용)
   - **Sandwich**: 양방향 병행

---

### Phase 2 — 계약(Contract) 및 시나리오 설계

각 통합 지점에 대해 Consumer(호출자)와 Provider(제공자) 간 인터페이스 계약(요청/응답 스키마, 상태 코드, 사전/사후 조건, 에러 형식)을 정의하고 4가지 핵심 시나리오를 설계한다:

1. **정상 경로 (Happy Path)**: 모듈 간 데이터 전달 및 직렬화/역직렬화 무결성
2. **경계 조건 (Boundary)**: 빈 컬렉션, 최대 페이로드, 타임아웃 경계
3. **오류 전파 및 복구 (Error Propagation)**: 하위 모듈 실패 시 상위 모듈의 에러 처리, 트랜잭션 롤백, 리소스(소켓/파일/메모리) 해제
4. **동시성 및 멱등성 (Concurrency & Idempotency)**: 중복 요청 처리 및 경쟁 조건(Race Condition) 방지

---

### Phase 3 — 테스트 하네스 및 통합 테스트 코드 작성

- 테스트 간 공유 상태(DB 테이블, 임시 파일, 전역 설정)가 오염되지 않도록 `setUp`/`tearDown` 또는 트랜잭션 롤백으로 격리한다.
- 외부 유료 API나 불안정한 서드파티 네트워크는 로컬 Stub/Mock 서버로 격리한다.

---

### Phase 4 — 단계적 실행 및 장애 경계 격리

작성한 통합 테스트를 직접 실행하고 실패 시 장애 지점을 격리한다 (`accuracy.md` 준수).

```text
실패 발생 시 격리 기준:
  ├── 입력값이 인터페이스에 도달하지 않음 → 호출 모듈(Consumer) 문제
  ├── 요청/응답 스키마·타입 불일치       → 인터페이스 계약 위반 (양쪽 대조)
  ├── Provider가 잘못된 결과/예외 반환   → 제공 모듈(Provider) 내부 버그
  └── 정상 응답을 Consumer가 잘못 처리   → 호출 모듈(Consumer) 후처리 버그
```

## 출력 형식

```markdown
## 🔗 통합 테스트 리포트

### 통합 구조 및 전략
- **통합 전략**: [Bottom-Up / Top-Down / Sandwich] ([선택 근거])
- **실행 명령**: `[실행한 테스트 명령어]`
- **결과**: 전체 N개 (✅ 통과 N / ❌ 실패 N / ⏭️ 스킵 N)

### 통합 지점 및 계약 검증 결과
| ID | Consumer → Provider | 시나리오 | 계약 준수 | 결과 |
| :--- | :--- | :--- | :--- | :--- |
| IT-01 | `OrderService` → `Inventory` | 정상 예약 (200) | ✅ | ✅ PASS |
| IT-02 | `OrderService` → `Inventory` | 재고 부족 오류 전파 (409) | ✅ | ✅ PASS |

### ❌ 실패 경계 격리 분석 (해당 시)
- **실패 경계**: `[모듈 A] → [모듈 B]`
- **원인 분류**: [Consumer 버그 / Provider 버그 / 계약 불일치 / 환경 문제]
- **데이터 추적**: 입력 `[...]` → 예상 `[...]` / 실제 `[...]`
- **권장 조치**: [구체적 수정 방향]
```
